# Seguridad

Este proyecto puede almacenar datos de alumnado y resultados de aprendizaje. No publiques bases de datos, ficheros `.env`, copias de seguridad ni enlaces personales del alumnado.

Para comunicar una vulnerabilidad, utiliza **GitHub → Security → Report a vulnerability / Private vulnerability reporting** si está habilitado. No publiques credenciales ni datos personales en Issues.

Recomendaciones mínimas de despliegue:

- HTTPS obligatorio en producción.
- Contraseña de administración robusta y exclusiva.
- Copias de seguridad protegidas.
- Actualizaciones periódicas mediante `upgrade.sh`.
- PIN y bloqueo de dispositivo para evaluaciones cuando proceda.
- Aplicar la normativa de protección de datos correspondiente al centro educativo.
